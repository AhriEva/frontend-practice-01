# Персональная страница Матвея Потапова

Учебная страница-визитка, созданная во время практик по фронтенд-разработке.
Проект последовательно развивает настройку рабочего окружения, работу с Git,
семантическую HTML-разметку и оформление страницы с помощью CSS.

## Как открыть проект

1. Откройте папку проекта в Visual Studio Code.
2. Откройте файл `index.html`.
3. Нажмите **Open with Live Server** или кнопку **Go Live**.
4. Для обычного просмотра можно открыть `index.html` двойным щелчком.

## Что есть на странице

- адаптивная шапка с навигацией;
- первый экран с авторской иллюстрацией;
- разделы «Обо мне», «Навыки», «Обучение и цели»;
- четыре карточки проектов;
- контактные ссылки;
- мобильная версия для экранов уже 700 пикселей.
